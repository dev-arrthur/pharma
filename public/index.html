Como utilizar

1. Escolha uma categoria no menu lateral.

2. Use a pesquisa para encontrar um registro pelo campo desejado.

3. Clique em Ver detalhes para conferir as informações.

4. Baixe o CSV ou salve a página atual em HTML para consultar offline.
